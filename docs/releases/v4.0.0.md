# Diski 9 v4.0.0 — Weekly Challenge functional prototype

**Release date:** 19 November 2026. **Status:** accepted functional prototype;
not deployed publicly.

## What this release is

The Weekly Challenge is complete as an interactive prototype, playtested and
accepted by the product owner (Phase 6B). It demonstrates the full participant
journey on real round data:
* build a strict nine-pick portfolio (4 Foundation, 3 Balanced, 2 Challenger)
  from a frozen round snapshot, with fixed 40/30/20/10 virtual credits;
* study the portfolio with market, Diski 9 and Your View probabilities, exact
  payouts and the 512-combination correct-predictions analysis;
* confirm, replace or withdraw a submission before the deadline;
* review it in My Challenge and explore demonstration leaderboards.

## What this release is not

* **No user accounts.** Everything is stored in the browser session
  (`sessionStorage`) of one tab; closing the tab clears it.
* **No permanent portfolios.** Submissions are not stored on a server and are not
  authoritative.
* **No automated settlement.** Results are not settled; leaderboards use
  demonstration data.
* **No real multiplayer competition** and no public deployment.

These arrive in Phase 6C (backend and persistence) and later phases.
